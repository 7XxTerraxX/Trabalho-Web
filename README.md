# Nexus Play — Loja de Video Games

## Sobre o projeto

O **Nexus Play** é um projeto acadêmico de desenvolvimento Front-End que consiste na criação de um site para uma loja fictícia especializada em jogos, consoles e acessórios de videogames.

O objetivo do projeto é desenvolver uma plataforma visualmente organizada, intuitiva e responsiva, permitindo que os usuários naveguem pelo catálogo de produtos, consultem informações e interajam com diferentes funcionalidades do site.

## Funcionalidades

O site conta com as seguintes páginas e recursos:

- **Home:** página inicial com produtos em destaque e novidades.
- **Jogos:** catálogo de jogos com campo de pesquisa e carrinho de compras.
- **Consoles:** apresentação dos consoles disponíveis.
- **Galeria:** exposição visual de produtos e conteúdos relacionados.
- **Comparativo:** tabela para comparação de produtos.
- **Ofertas:** apresentação de produtos em promoção.
- **FAQ:** perguntas frequentes.
- **Sobre:** informações sobre a loja Nexus Play.
- **Contato:** formulário para envio de mensagens.
- **Cadastro:** página de cadastro de usuários.

Além disso, o projeto possui recursos interativos, como carrinho de compras, contador de itens, cálculo automático do valor total e armazenamento de informações no navegador.

## Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e organização visual.
- **JavaScript:** implementação das funcionalidades e interações.
- **Bootstrap 5.3.3:** auxílio na criação de layouts responsivos e componentes visuais.
